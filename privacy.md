# Política de privacidad de Sonora

**Última actualización: 4 de noviembre de 2026**

Sonora es un reproductor de música para Android desarrollado para uso personal. La aplicación funciona en el dispositivo y no utiliza servidores propios del desarrollador.

## 1. Información que Sonora utiliza localmente

Para permitir la reproducción y mostrar la información de las canciones, Sonora puede acceder a los archivos de audio que el usuario seleccione y a sus metadatos, como título, artista, álbum y duración. Esta información se utiliza localmente para las funciones del reproductor.

## 2. Conexión con Discord

Sonora puede conectarse a Discord cuando el usuario activa la integración de Rich Presence. En ese caso, la información necesaria para mostrar la actividad musical —por ejemplo, el nombre de la canción, el artista y los datos de actividad o reproducción— se transmite a Discord.

Esta comunicación se realiza con Discord y está sujeta también a los términos y a la política de privacidad de Discord. Sonora no controla cómo Discord trata la información que recibe.

La integración con Discord es opcional. Si el usuario no la activa, Sonora no debería enviar información de reproducción a Discord.

## 3. Servidores, analíticas y publicidad

Sonora no opera un servidor propio para recopilar o almacenar información de sus usuarios. El desarrollador no utiliza la aplicación para recopilar analíticas, telemetría ni datos con fines publicitarios.

## 4. Cuentas y credenciales

Sonora no solicita ni necesita la contraseña de la cuenta de Discord. El usuario no debe introducir contraseñas, tokens privados ni secretos de aplicaciones en campos que no estén expresamente diseñados para un flujo oficial y seguro de autenticación.

## 5. Archivos y permisos

Los permisos de Android se utilizan únicamente para las funciones que el usuario decide utilizar, como acceder a música local o mostrar controles multimedia. El usuario puede administrar los permisos desde los ajustes de Android.

## 6. Menores y uso personal

Sonora es un proyecto de uso personal y no está diseñado como un servicio público. Si se comparte una copia de la aplicación, quien la distribuya debe proporcionar esta política y respetar la legislación aplicable.

## 7. Cambios en esta política

Esta política puede actualizarse si cambian las funciones de Sonora o la forma en que se comunica con servicios externos. La fecha de actualización aparecerá al inicio del documento.

## 8. Contacto

Sonora es un proyecto personal. Para consultas sobre esta política, utiliza el medio de contacto que el desarrollador publique junto con la aplicación, si lo proporciona.
